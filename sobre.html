Sobre o projeto

O Colei! é um álbum de figurinhas digital da Copa do Mundo de 2026. Foi feito como Projeto Final da disciplina Desenvolvimento de Interfaces, do CEUB.

É um projeto acadêmico, sem fins comerciais e sem vínculo com a FIFA, a Panini ou as federações.

O que é de verdade

  • As seleções, os jogadores, os clubes, os resultados e os estádios vêm de pesquisa. Cada dado tem a fonte anotada.
  • O que não foi possível confirmar aparece escrito como "a confirmar".
  • As fotos, as bandeiras e as fontes de letra têm licença livre, com o crédito mais abaixo.

O que é simulado

  • Não existe servidor. O álbum, a conta e as preferências ficam guardados só no navegador em que o site foi aberto.
  • O login serve para separar o álbum de cada pessoa neste navegador. Não é um login de verdade.
  • O formulário de contato confere os campos, mas não envia a mensagem.
  • A banca de trocas sorteia as ofertas. Não há outra pessoa do outro lado.
  • O retrato das figurinhas é um desenho genérico. Não representa nenhum jogador.

Como foi feito

  • HTML, CSS e JavaScript puros, sem framework e sem etapa de build. O site abre direto do arquivo index.html.
  • Uma única biblioteca, a Three.js, usada só para desenhar o pacotinho em 3D.
  • Sete páginas com o mesmo cabeçalho e o mesmo rodapé.
  • Meta de acessibilidade: WCAG 2.2, nível AA, nos temas claro e escuro. O contraste de cada par de cores é calculado por um script.
  • Tudo funciona pelo teclado. O que se faz arrastando também se faz por botão.
  • O histórico de versões fica no GitHub, com uma marca em cada etapa.
  • Inteligência artificial usada: Claude Code (modelo Claude, da Anthropic), para escrever código, pesquisar os dados e montar a documentação técnica, a partir das decisões do aluno.

Desenhos do fundo

O estádio, a bola, as bandeirinhas e os outros recortes do fundo foram desenhados para este projeto, por código. Não usam foto nem imagem de fora.

Biblioteca de 3D

Biblioteca Three.js, revisão 128, dos autores do three.js. Licença MIT. Desenha o pacotinho em 3D na página Pacotinhos e gerou as imagens do pacotinho da página inicial.

Fotos dos estádios

Todas vêm do Wikimedia Commons. Foram reduzidas para 960 pixels de largura e, no site, aparecem na cor da tinta da página por um efeito feito no CSS. O link de cada linha leva à foto original.

      Modo demonstração

      Feito para a apresentação: dá para testar o álbum inteiro sem esperar um pacotinho por dia. Vale só para este navegador.

      Zerar o álbum?

      Isso apaga as figurinhas, as coladas, os pacotinhos extras, a sequência e as conquistas guardadas neste navegador. Não dá para desfazer.

      Guia de estilo

      As peças que o site usa, todas juntas. Troque o tema no botão Acessibilidade e veja como cada uma se comporta.
